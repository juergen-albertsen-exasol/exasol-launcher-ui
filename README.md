# Exasol Local UI

A prototype web UI for local [Exasol Personal](https://github.com/exasol/exasol-personal)
deployments: database health, sidecar management, and a SQL editor, with the
look and feel of the Exasol Administration UI.

The project is an early prototype and not yet usable. See [AGENTS.md](AGENTS.md)
for its architecture and workflow, and [openspec/](openspec/) for its
specifications and planned changes.
